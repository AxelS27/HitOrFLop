# 🌐 Music Hit Predictor: System Guide

A high-performance technical dashboard for audio analytics. This interface bridges complex machine learning inference with premium visualization.

## 🧩 Architectural Layout

### 1. The DNA System (Technical Inspector)
A contextual spectral visualizer providing a deep dive into audio characteristics.
- **Real-Track Fingerprint**: Maps 5 core acoustic dimensions.
- **Spectral Waveform**: Real-time CSS-animated waveform.
- **Terminal Logs**: Live-scrolling event protocol.

### 2. Prediction Engine
Custom form handling for local MP3 uploads and YouTube URL parsing.
- **Logic**: Communicates with the Hugging Face Inference API.
- **Theming**: UI adapts dynamically based on success probability.

## 🛠️ Stack Summary
- **Frontend**: React 18, Vite, TypeScript.
- **Styling**: Vanilla CSS (No-Dash Design).
- **Backend API**: FastAPI (Hugging Face Spaces).
